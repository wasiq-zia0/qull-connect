Build API documentation for our 10 Qull Connect connectors on qull.io.

For each connector below, host on qull.io under its existing connect folder:
1. Its OpenAPI spec file (exact JSON is pasted below each FILE header — save it verbatim, keep the filename, e.g. deposit-recovery.json).
2. An API docs page that renders the spec with Swagger UI — use swagger-ui-dist from CDN (https://cdn.jsdelivr.net/npm/swagger-ui-dist@5). The page must load its spec via a relative path.

Suggested URL pattern (adjust to the existing folder structure):
- qull.io/connect/<existing-connector-folder>/api-docs  -> the docs page
- qull.io/connect/<existing-connector-folder>/api-docs/<slug>.json  -> the spec file

Requirements:
- Match the header, footer, fonts, and styling of our existing qull.io/connect/ pages.
- Each docs page gets a clear title, e.g. "Deposit Recovery — API documentation".
- Describe authentication only from a verified implementation contract. The current specs omit security schemes; do not invent the header name, identity protocol, or credential provisioning flow. Keep request execution disabled until these are verified.
- Clean URLs, no .html extension. Mobile-friendly.
- Reply with all 10 docs page URLs and all 10 spec file URLs, plus a list of anything you were unsure about.
